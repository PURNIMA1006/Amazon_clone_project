# 🛒 Amazon Clone

A responsive front-end clone of the Amazon homepage built using **HTML5** and **CSS3**. This project was created to strengthen my understanding of web development fundamentals, responsive layouts, and modern UI design.

## 🚀 Features

* Amazon-inspired homepage layout
* Responsive navigation bar
* Search bar UI
* Hero section with banner
* Product category cards
* Footer similar to Amazon
* Responsive design for different screen sizes
* Clean and organized code structure

## 🛠️ Tech Stack

* HTML5
* CSS3
* Font Awesome (Icons)

## 💻 Getting Started

1. Clone the repository

bash

git clone https://github.com/PURNIMA1006/Amazon_clone_project.git

2. Open the project folder.

3. Run the project by opening index.html in your browser or by using **Live Server** in VS Code.
